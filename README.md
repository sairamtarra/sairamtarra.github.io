# Sairam Tarra — Portfolio

A modern, responsive developer portfolio built with **React**, **Vite**, and **CSS**.  
Showcases projects, skills, education, certifications, and a working contact form.

---

## Features

- Blazing fast dev server & build with **Vite**
- Clean, responsive design – adapts perfectly to mobile, tablet, and desktop
- Single data file (`data.js`) – update your info without touching components
- Working contact form (opens your default email client)
- Projects section with "View All" toggle
- Skills grouped by category with visual icons
- Education & Certifications side‑by‑side layout
- Social & resume links in the navbar
- Sticky navbar with glass‑morphism effect

---

## Getting Started

### Prerequisites
- Node.js **16+** (recommended: 18 or 20)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/sairamtarra/sairamtarra.github.io.git

# Navigate into the folder
cd my-portfolio-react

# Install dependencies
npm install

# Start the development server
npm run dev
The app will be running at http://localhost:5173 (or the port Vite shows).

Build for Production
bash
npm run build
The output will be in the dist/ folder – ready to deploy to Vercel, Netlify, GitHub Pages, or any static host.

Deployment
Vercel
Push your code to a GitHub repository.

Push to GitHub.

Build command: npm run build
Publish directory: dist

Deploy.

Customisation
All personal information, projects, skills, and links live in one file: src/data.js

Just edit that file to make the portfolio yours:

personal → name, role, contact links, profile picture

projects → add/remove project objects

skills → change categories and icons

education / certifications → update as needed

The UI will update automatically!
